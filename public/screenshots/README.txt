Optional real app screenshots.

Set "screenshots" on an app in src/data/apps.js, for example:
  screenshots: ["/screenshots/clipdropper-1.png", "/screenshots/clipdropper-2.png"]

Recommended: portrait PNG/JPG at 1080x2340 (or any 9:19.5 ratio).
When screenshots is empty, the site renders the mock screens defined in "screens".
